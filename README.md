Welcome to the initial release of **File Converter**! 

This powerful application allows you to effortlessly convert between a wide variety of formats right from your device. Designed with privacy in mind, all conversions happen locally—no cloud uploads required.

###  Key Features
- **Image Conversion**: Effortlessly convert between major image formats (PNG, JPG, WebP, etc.).
- **Audio & Video**: Fast processing for media files.
- **Document & PDF**: Convert and handle data documents securely.
- **Offline & Private**: Your files never leave your computer.
- **Portable**: Ready to run anywhere with our portable Windows executable.

###  Assets Included
- `File Converter 1.0.0.exe` - Portable executable for Windows.
- `logo.png` - Application Icon.
